Ce bookmarklet ouvre automatiquement LeBonCoin avec les filtres du véhicule Alcopa que vous consultez.

Le Bookmarklet

Glissez ce bouton dans vos favoris :

🔍 Alcopa → LBC

Installation sur iPhone/iPad

Étape 1 : Ajouter aux favoris

Sur cette page, appuyez sur le bouton Partager (carré avec flèche) puis "Ajouter un signet".

Étape 2 : Modifier le favori

Allez dans vos Favoris, trouvez le signet que vous venez d'ajouter, et appuyez sur Modifier.

Étape 4 : Utilisation

Sur une fiche véhicule alcopa-auction.fr, ouvrez vos favoris et cliquez sur "Alcopa → LBC". LeBonCoin s'ouvrira avec les bons filtres !

⚠️ Note iOS : Sur iPhone, les pop-ups peuvent être bloqués. Si LeBonCoin ne s'ouvre pas, autorisez les pop-ups dans Réglages → Safari → Bloquer les pop-ups → Désactivé.
